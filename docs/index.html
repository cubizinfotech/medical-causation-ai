Medical Causation AI

Enterprise SaaS platform for personal injury attorneys to evaluate medical causation using scientific evidence and AI.

Phase 1 — Project Foundation

Project Purpose

Medical Causation AI helps personal injury attorneys determine whether a trauma or accident medically contributed to a patient's injury or disease. The platform is not a hospital system, EMR, or medical diagnosis tool.

Attorneys use the platform to answer questions such as:

  • Did a car accident contribute to a patient's stroke?
  • Did trauma worsen a spinal injury?
  • Did a workplace accident increase the risk of a disease?
  • Can scientific evidence support medical causation?

Instead of manually reading hundreds of medical papers, the platform automatically searches trusted medical databases, retrieves relevant scientific evidence, analyzes it using AI, applies accepted causation principles, and generates attorney-ready professional reports with citations.

Demo Workflow

The full application workflow (target state):

1
Attorney creates a medical causation case with patient and accident details
2
System searches PubMed, PMC, ClinicalTrials.gov, and other medical databases
3
Private knowledge base (textbooks, articles, reports) is searched via RAG
4
AI analyzes retrieved evidence and applies medical causation principles
5
Probability engine calculates causation confidence scores
6
Professional PDF report is generated with full citations
7
Attorney downloads the report for case use

Local Setup

Prerequisites: Node.js 20+, npm 10+, Git

# Clone and configure
git clone <repository-url>
cd medical-causation-ai
cp .env.example .env

# Backend (port 3001)
cd apps/api
npm install
npm run start:dev

# Frontend (port 3000) — separate terminal
cd apps/web
npm install
npm run dev

Open http://localhost:3000 for the frontend. The backend runs at http://localhost:3001.
