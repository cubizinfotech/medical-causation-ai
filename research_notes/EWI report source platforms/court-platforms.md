# Court, docket, deposition, and testimony platforms for EWI reports

Research notes for Expert Witness Investigation (EWI) reports used by US personal-injury attorneys (Florida and other states). Prices in USD. Pages accessed 27 October 2026 unless a source itself is dated earlier. Distinguishes **human subscription** (a lawyer or paralegal logs in) from **NestJS wire-in** (an official API or licensed bulk feed the app can call). Does not recommend scraping behind login.

Re-verification of `docs/ewi/provider-register.md` (dated 22 October 2026): PACER $0.10/page, $3 document cap, $30 quarterly waiver, 2027 move to $0.12 and $40 waiver, CourtListener REST token, recap-fetch PACER-credential model, and TrialSmith $28–$50 downloads are still accurate. Two items changed or need correction: (1) CourtListener default REST throttles are now **5/min, 50/hour, 125/day**, not the older “5,000/hour” figure still visible on some cached pages; (2) TrialSmith Pro is marketed as a **$749 value**, but the live join page still hides the actual subscription list price behind an association selector.

## CourtListener REST vs recap-fetch vs PACER: what is free, what bills per page, password rotation, and whether EWI can legally automate it

### Takeaway
CourtListener REST is the only court stack that can be wired into NestJS today at $0 API cost, but it only returns what is already in the RECAP Archive plus published opinions—not a complete federal docket. Recap-fetch is a free CourtListener API that **buys** missing PACER pages on the client’s PACER bill ($0.10/page, $3 cap, $30/quarter auto-waiver in 2026). Direct PACER login from NestJS is legally constrained, operationally brittle (180-day password rotation, MFA cookie failures), and is not a public REST API.

### Cited Findings
- CourtListener REST v4.7 is a public JSON/XML API covering case law, PACER/RECAP objects (dockets, entries, documents, parties, attorneys), search, judges, oral arguments, alerts, and citation lookup. Many endpoints are open by default; production use requires a token. Accessed 27 Oct 2026. — [CourtListener REST API](https://www.courtlistener.com/help/api/rest/)
- Default authenticated REST limits are **5 requests/minute, 50/hour, and 125/day**, rolling windows, concurrent throttles. Creating more than one account per project/person/organization is forbidden. Commercial agreements are offered for higher limits. Accessed 27 Oct 2026. — [CourtListener REST API](https://www.courtlistener.com/help/api/rest/)
- An older cached REST page (labeled v4.3) still states “5,000 queries per hour to authenticated users.” That conflicts with the live v4.7 documentation. — [Cached REST v4.3](https://courtlistener.com/help/api/rest); contradicted by [REST v4.7](https://www.courtlistener.com/help/api/rest/)
- Free Law Project membership raises REST limits: Tier 1 $10/mo or $100/yr → 10/min, 75/hour, 300/day; Tier 2 $25/mo or $250/yr → 15/min, 150/hour, 600/day; Tier 3 $50/mo or $500/yr → 20/min, 250/hour, 1,000/day; Tier 4 $100/mo or $1000/yr → 25/min, 300/hour, 1,400/day. Free non-member tier is the 5/50/125 default. Group plans start at $30/mo (1–5 seats, Tier 1) up to $2,500/mo (up to 100 seats, Tier 4). Accessed 27 Oct 2026. — [Free Law Project Membership](https://free.law/membership/)
- Membership-based API access is **not** for a revenue-positive commercial product or for internal tooling at a for-profit org. Solo practitioners and firms with **five or fewer attorneys** may use membership API access; firms with more than five attorneys are told to discuss a commercial agreement. “Internal tooling that supports an organization's operation” is treated as commercial use. Accessed 27 Oct 2026. — [Membership-Based API Usage Restrictions](https://free.law/membership/allowed-api-usage/)
- Bulk CSV snapshots (case law, dockets, judges, oral arguments, embeddings) are regenerated quarterly (last day of Mar/Jun/Sep/Dec). Files are full snapshots, not deltas, streamed to S3. — [Bulk Legal Data](https://www.courtlistener.com/help/api/bulk-data/)
- Database replication (PostgreSQL logical replica: case law, RECAP Archive, FJC civil data, oral arguments, financial disclosures, judges) is arranged with Free Law Project, not a self-serve SKU. User data is never replicated. — [Database Replication](https://courtlistener.com/help/api/replication/)
- Recap-fetch (`POST /api/rest/v4/recap-fetch/`) “is a free API, but it uses your PACER credentials to purchase and download PACER content. You'll still have to pay your PACER bill when it comes.” Request types include dockets (`request_type=1`), PDFs (`2`), and attachment pages (`3`, which CourtListener says are free in PACER). Asynchronous; poll or use a webhook. Accessed 27 Oct 2026. — [RECAP APIs](https://www.courtlistener.com/help/api/rest/v4/recap/)
- Recap-fetch does **not** store the PACER password: it logs in, caches cookies in memory for one hour, then discards username/password. Fetching a sealed item on the client’s credentials will still retrieve it and add it to CourtListener; CourtListener warns “Do not do this.” — [RECAP APIs](https://www.courtlistener.com/help/api/rest/v4/recap/)
- “As of 2025, the federal judiciary requires that all PACER accounts change their passwords every 180 days.” If the password expires, recap-fetch cannot log in. CourtListener recommends **two PACER accounts** and rotating them in code to avoid downtime. MFA can break login (`PacerLoginException: Did not get NextGenCSO cookie`); CourtListener’s documented workaround is temporarily disabling MFA. Accessed 27 Oct 2026. — [RECAP APIs](https://www.courtlistener.com/help/api/rest/v4/recap/)
- PACER password rotation is also stated by PACER itself: passwords must be updated every 180 days; users may skip the prompt three times before lockout; new password rules (14–45 characters, mixed case + special, no name/username/email) began enforcement 17 August 2026. Teams sharing an account are told to coordinate. Third-party software users are told to check whether they need extra action. — [Updated Password Standards Enforcement](https://pacer.uscourts.gov/announcements/2026/06/10/coming-soon-updated-password-standards-enforcement)
- Official EPA fee schedule (effective 1 Jan 2020, still the live schedule on 27 Oct 2026): **$0.10 per page** for case documents, docket sheets, and case-specific reports, **not to exceed the fee for thirty pages** ($3.00). Transcripts and non-case-specific reports (PACER Case Locator, docket activity reports) are $0.10/page **with no 30-page cap**. Audio files $2.40 each. Courthouse terminal printouts $0.10/page. PACER Service Center search-for-you: $30 per name/item. Returned payment $53. — [Electronic Public Access Fee Schedule](https://www.uscourts.gov/court-programs/fees/electronic-public-access-fee-schedule)
- PACER FAQ: HTML pages billed at 4,320 bytes = 1 page; PDFs billed by actual page count. A search with no matches still costs $0.10. “If you accrue $30 or less of charges in a quarter, fees are waived for that period. 75 percent of PACER users do not pay a fee in a given quarter.” Opinions are free. Parties/attorneys of record get one free copy via NEF. — [PACER Pricing FAQs](https://pacer.uscourts.gov/help/faqs/pricing); [PACER Pricing: How fees work](https://pacer.uscourts.gov/pacer-pricing-how-fees-work)
- Automatic waiver is **per account**. A PACER Administrative Account (PAA) consolidates firm logins; the $30 waiver then applies only if the **firm total** is under $30. — [PACER Policy & Procedures](https://pacer.uscourts.gov/policy-procedures)
- Temporary fee increase **effective 1 January 2027**: $0.10 → **$0.12 per page** for five years; quarterly auto-exemption **$30 → $40**. First per-page change since 2012. Announced 26 June 2026. — [Temporary Fee Increase Effective Jan. 1, 2027](https://pacer.uscourts.gov/announcements/2026/06/26/temporary-fee-increase-effective-jan-1-2027)
- PACER Policy: “Any attempt to collect data from PACER in a manner that avoids billing is strictly prohibited and may result in criminal prosecution or civil action.” Misuse expressly includes “using an automated process to repeatedly access those portions of the PACER application that do not assess a fee (i.e., calendar events report or case header information) for purposes of collecting case information.” Accounts causing congestion may be suspended. Account is “for my use only, unless specifically designated otherwise on the registration form.” — [PACER Policy & Procedures](https://pacer.uscourts.gov/policy-procedures)
- PACER does **not** ban all automation. An official 9 Oct 2024 announcement addresses “data-scraping scripts”: large pulls only **6 p.m.–6 a.m. Central**; reuse the NextGenCSO cookie rather than re-authenticating; from 1 Jan 2025, excessive auth calls that disrupt operations may suspend access. — [Reminder and Tips for Automated Script Users](https://pacer.uscourts.gov/announcements/2024/10/09/reminder-and-tips-automated-script-users)
- Recap-fetch is a CourtListener-supported way to buy PACER content **without** EWI writing its own PACER scraper. The upload API (`/api/rest/v4/recap/`) is **not public**; it is for the RECAP browser extension and special partners. — [RECAP APIs](https://www.courtlistener.com/help/api/rest/v4/recap/)
- Pray-and-Pay (`/api/rest/v4/prayers/`) lets an account request a PACER PDF that is not yet in RECAP; when someone else buys it, the prayer is granted. Standard users have a daily prayer quota (5 on the free web tier; 15 on paid membership). — [RECAP APIs](https://www.courtlistener.com/help/api/rest/v4/recap/); [Membership](https://free.law/membership/)
- Unique evidence REST-only can add to an opposing-expert report: published federal/state **opinions** that name the expert (Daubert/Frye/Rule 702 language in the opinion text), RECAP **docket metadata and already-purchased PDFs** (motions in limine, Daubert orders, complaints where the expert is a party), party/attorney tables, and oral-argument audio metadata. It cannot guarantee a complete docket, a deposition transcript, or an unpublished trial-court challenge. — [CourtListener REST API](https://www.courtlistener.com/help/api/rest/); [RECAP APIs](https://www.courtlistener.com/help/api/rest/v4/recap/)

### Inferences
- For EWI NestJS: **wire CourtListener REST now** (token in env; already in the provider register as working). Treat it as “search + whatever RECAP already has,” not as PACER-complete.
- Recap-fetch is the **only documented, vendor-supported automation path** to fill missing federal PDFs. It is legally cleaner than a homegrown PACER scraper because (a) PACER bills are paid, (b) CourtListener’s ToS invite this use, and (c) PACER’s own script guidance is about congestion and billing avoidance, not a blanket automation ban. It is still **not** “free PACER.”
- Whether EWI “can legally automate PACER” depends on the product posture. If medical-causation-ai is sold as a commercial EWI product, Free Law Project membership API access is **out of bounds**; a commercial CourtListener agreement is required, plus a PACER account that is not used to dodge fees. Direct PACER HTML scraping from NestJS remains a gray, high-ops path (MFA, 180-day passwords, off-hours, no public API) even if PACER acknowledges scripts.
- Sharing one PACER password with CourtListener violates the usual security maxim; CourtListener documents why it is required (PACER has no delegated auth). EWI should store PACER credentials in a secret store, never git, and plan dual-account rotation.
- Typical per-investigation PACER cost if recap-fetch is used conservatively (search + one docket + a handful of motions, staying under the $3 cap): often **$0** if the quarterly waiver still has room, else **a few dollars to ~$30**. Uncapped **transcripts** are the cost blow-up, not ordinary Daubert motions.

### Gaps
- CourtListener commercial-agreement list prices are not published; Free Law Project says “contact partnerships.” No 2026 dollar figure found.
- Replication service pricing is not on the public replication page.
- No official PACER REST API exists; there is no judiciary-published “yes you may automate expert-name searches from a SaaS” letter. Legal risk for a commercial NestJS product that logs into PACER directly (rather than via recap-fetch) was not answered by counsel-grade authority in this pass.
- Recap-fetch + MFA: CourtListener’s only public workaround is disabling MFA, which is a security tradeoff not quantified in PACER docs.
- How often RECAP already contains the Daubert motion for a typical Florida MD/SD expert was not measured.

## TrialSmith / TrialSmith Deposition Bank: API, subscription tiers, typical PI firm cost

### Takeaway
TrialSmith is the plaintiff-side deposition bank that uniquely fills **full expert transcripts** public HTML cannot touch. There is **no public API**. Membership list price is not on the public pricing page (association-gated); the only hard public numbers are **$28–$50 per download**, **up to $30 credit per contributed transcript**, and a contributor promo that values Pro at **$749 / 12 months**. It can be bought for a human researcher; it cannot be wired into NestJS without a private license TrialSmith does not advertise, and scraping it is contractually forbidden.

### Cited Findings
- Depositions are “free to read online for Pro-Plan Members, and **$28 to $50** if you decide to download a copy. The download cost is variable depending on costs to acquire the transcript.” Ala-carte purchase is offered as an alternative to membership. Accessed 27 Oct 2026. — [Deposition Pricing](https://www.trialsmith.com/?pg=DepositionPricing)
- Contributors earn “up to **$30** in purchase credit for each new expert transcript (experts, doctors, corporate reps).” Credits auto-apply to downloads. Upload is drag-and-drop or email to depositions@trialsmith.com. — [Deposition Pricing](https://www.trialsmith.com/?pg=DepositionPricing)
- Marketing page: “SEND 100 NEW transcripts and start a free membership” → “Free 12 Month Pro Plan Membership (**$749 Value**)” that “does not automatically renew,” plus “full access to Decisis Legal Research… a **$850 Value**.” “More than **740,000** depositions are available.” “Plaintiff lawyers share more than 30,000 new transcripts each year.” “68 partner trial lawyers associations.” Plaintiff-only; 90% of proceeds support trial lawyer associations. Contradictory promo copy on the same page also says “waive your first **6 months** fee when you contribute 100” vs 12-month free Pro. Accessed 27 Oct 2026. — [TrialSmith Membership / contributors](https://www.trialsmith.com/?pg=Free-Trial--for-Contributors)
- Join page: “Choose your association to view plans and pricing.” If unaffiliated, select “I am not affiliated with any of these associations.” No dollar amounts render without that step. Phone 800-443-1757. — [Membership Application](https://www.trialsmith.com/?pg=joinTrialsmith)
- User Requirements (contract): customer warrants they “(i) are engaged primarily in representing **plaintiffs** in litigation, (ii) do not represent defendants… (iii) do not represent any insurance company, and (iv) are licensed to practice law in the United States or Canada.” Failure requires immediate notice and discontinuation. — [Terms & Conditions](https://www.trialsmith.com/?pg=TermsAndConditions)
- Access restrictions: no sharing except paralegals under direct employment; no research for anyone else; no service-bureau / resale / republish of TrialSmith Content. Firm Account members may share purchased content with other registered firm members. — [Terms & Conditions](https://www.trialsmith.com/?pg=TermsAndConditions)
- Section 5.4 Key Features include “the plaintiff only lawyer online database,” “single-search access tool to depositions, expert witness reports, **Daubert Challenge reports**, disciplinary actions, expert challenges and list servers.” Customer may not “build a competitive product or service or any product or service containing any of the Key Features,” copy features, or prepare derivative works of Key Features. Injunctive relief without bond is reserved. — [Terms & Conditions](https://www.trialsmith.com/?pg=TermsAndConditions)
- Fees: Subscription Fee (annual or monthly) + Content Fees. Subscription Fees change without notice at renewal; Content Fees can change during the term (price shown at purchase). Default term 12 months; **service orders do not auto-renew**. Credits never expire, not redeemable for cash. — [Terms & Conditions](https://www.trialsmith.com/?pg=TermsAndConditions)
- No public REST/GraphQL documentation, developer portal, or API key product was found on trialsmith.com in this research pass (join, pricing, terms, contributor pages).
- Unique evidence vs a public-HTML EWI report: **verbatim prior deposition testimony** of the opposing expert (impeachment, methodology admissions, fee history, plaintiff vs defense mix), plus in-product Daubert-challenge reports and disciplinary items TrialSmith indexes from member contributions—not PACER opinions. Defense-side firms cannot buy it. — [Deposition Pricing](https://www.trialsmith.com/?pg=DepositionPricing); [Terms](https://www.trialsmith.com/?pg=TermsAndConditions)

### Inferences
- Typical PI (plaintiff) firm cost, based only on public numbers: **Pro ~$749/year list-adjacent** if the $749 “value” is close to what unaffiliated firms pay, plus $0 if staff only read online, plus $28–$50 per downloaded transcript they actually attach to a file, offset by $30 credits for each depo the firm contributes. That is a **human workflow**, not an API cost. Association-member firms likely pay less; the join page exists specifically to show those rates.
- NestJS: **cannot wire**. A future “request TrialSmith” flag (already contemplated in the provider register) should open a staff task, not scrape the portal.
- Defense PI shops and mixed-practice firms that “represent defendants” are contractually ineligible. EWI sold to both sides cannot treat TrialSmith as a default source.

### Gaps
- Actual 2026 subscription tiers (monthly vs annual, seat counts, unaffiliated vs Florida Justice Association / AAJ rates) are behind the association picker; this research did not complete that form. **Quote-only.**
- Whether the $749 “value” equals current Pro list price, or is a discounted/marketing number, is not stated on the deposition pricing page.
- No documented bulk or API license for law-tech vendors.
- Coverage quality for Florida neuropsych / IME experts vs national experts was not sampled.

## LexisNexis (Lexis+) and Thomson Reuters Westlaw: expert / verdict / deposition products, API, small-firm vs enterprise pricing, scraping prohibition

### Takeaway
Both vendors hold the expert-challenge, verdict, and transcript libraries that would fill EWI’s empty Daubert/deposition/lawsuit sections, but **list prices for law-firm expert modules are mostly quote-only**. What *is* published: Lexis Expert Research On-Demand à-la-carte (a **2016** PDF still hosted: $164 testimonial history, $95 challenge report, $66/transcript), Westlaw Advantage **$256.75–$399.75/month** for new firms of ≤10 attorneys (research platform, not a promise that Profiler/transcripts are included), and both vendors’ current terms **ban scraping and unlicensed automation**. Licensed APIs exist behind sales; they are not a self-serve NestJS drop-in for expert transcripts.

### Cited Findings

**LexisNexis products and published prices**
- Lexis Expert Research On-Demand: no subscription; researchers deliver reports in 2–3 business days; rush available. Live marketing: “475K+ expert witnesses,” “1.4M collection of verdicts and settlements,” transcripts, depositions, disciplinary actions, challenges to exclude. Accessed 27 Oct 2026. — [Expert Witness Services / On-Demand](https://www.lexisnexis.com/en-us/products/expert-research-on-demand.page)
- Hosted “Services and Pricing” PDF (footer: information as of **October 2016**): Testimonial History **$164** (when successful); Enhanced Challenge Report **$95** (including opinions); Expert Witness Documents **$66 per transcript**, **$23** other documents; State License Discipline **$40**; articles-written search $44 + $5.50/abstract, $17–$27 full text. — [Expert Research On-Demand Services and Pricing PDF](https://www.lexisnexis.com/pdf/Expert-Research-On-Demand_Services-and-Pricing.pdf)
- The live On-Demand page on 27 Oct 2026 does **not** reprint those dollar amounts; the PDF remains the only official price sheet found. Treat 2016 figures as **possibly stale**.
- Lexis APIs (Protégé / REST / Cognitive, OAuth, JSON): access via request form; “API access and pricing depend on the specific products and data volumes”; no public per-call price. Search snippet 27 Oct 2026; the product page itself returned CloudFront 403 when fetched directly. — [Lexis APIs](https://www.lexisnexis.com/en-us/products/lexis-api.page)
- Developer Portal describes APIs for statutory/regulatory/legal/company/news content; it does not list an “expert deposition transcript” endpoint on the getting-started page. — [LexisNexis Developer Portal](https://dev.lexisnexis.com/gettingStarted/)
- Third-party 2026 recap of Lexis+ small-law published tiers (1–3 attorneys, new customers): Essential **$114/mo** (3-year) / $152 (1-year) single-state; Enhanced **$257 / $342** (+ federal, Practical Guidance, verdicts); Professional **$324 / $432** (+ 50-state, CourtLink, Law360); Deluxe Transactional **$217 / $289**. Firms 4+ attorneys: custom. Lexis+ AI / Protégé add-on reported **$125–$275/user/mo**. 2-year 10% off, 3-year 25% off. **This is not an official Lexis price card.** — [Spellbook LexisNexis Pricing 2026](https://spellbook.com/learn/lexisnexis-pricing)
- Third-party recap of 2026 Lexis out-of-plan schedule: Context Experts report **$99**; premium litigation document **$100**; verdict document **$53**; Verdict & Settlement Analyzer **$125**. **Westlaw / Thomson Reuters products and published prices**
- Westlaw Advantage FAQ (official, accessed 27 Oct 2026): pricing **starts at $256.75 per month** for single-circuit coverage and **$399.75 per month** for all-states-and-federal. 12% off 2-year, 18% off 3-year. Online pricing for **new** customers at firms of **up to 10 attorneys**; >10 attorneys contact sales; existing customers excluded from this online pricing (888-728-7677). Access typically within 1 business day. Includes Deep Research, Litigation Document Analyzer, KeyCite, etc. The FAQ does **not** name Expert Witness Profiler, Jury Verdicts, or deposition transcripts as included SKUs. — [Westlaw Advantage Plans](https://sales.legalsolutions.thomsonreuters.com/en-us/products/westlaw-advantage/plans-pricing)
- Expert Witness Profiler (Westlaw.com subscribers): summarizes relationships from case law, jury verdicts, dockets, briefs, trial documents, expert testimony; appearances from jury verdicts beginning 1993; expert depositions/testimony/reports beginning 1996; editor-selected admissibility cases from 2000. Expert Challenge and Expert Evaluator reports; document lists include testimony and trial pleadings. Accessing Profiler can be a **billable transaction** if not in the plan. — [Expert Evaluator Report FAQ PDF](https://www.experts.com/content/d/cv/EXPERT%20EVALUATOR%20REPORT.pdf); [West km help, Profiler billable note](http://help.westkm.com/server500/shared/viewing_documents_and_summaries.asp?admin=y&ann=&gx=&im=&ks=n&lit=y&lx=y&trans=&version=5.0.0&veted=&vetkit=)
- Third-party recap of Thomson Reuters **state and local government** schedule effective 1 Feb 2026: Expert Challenge Report **$143**, Expert Evaluation Report **$100**, expert depositions/reports/trial transcripts **$95 per document**. The recap warns law-firm order pages do not name Profiler as a line item. — [CaseSearch expert witness pricing](https://casesearch.ai/expert-witness-search)
- Westlaw APIs exist (Litigation Analytics, Legislation, others on the developer portal); keys via sales (“Connect with sales for a subscription”); no public API price or expert-transcript endpoint description found. Public API terms (UK product-specific, May 2023) prohibit using the API to train AI and restrict displaying content in third-party products. — [vaquill Westlaw API overview](https://www.vaquill.ai/blog/westlaw-api-what-exists-who-can-use-it-and-what-it-covers); [TR API Product Specific Terms (UK)](https://legalsolutions.thomsonreuters.co.uk/content/dam/ewp-m/documents/legal-uk/en/pdf/terms-conditions/api-product-specific-terms.pdf)

**Scraping / automation prohibitions**
- LexisNexis US General Terms, **effective 5 June 2026**, §1.2(a): “Access or use the Online Services via mechanical, programmatic, robotic, scripted or any other automated means is **strictly prohibited** without our express prior written permission.” Also bans storing Materials in a database (with a compliance exception), commercial resale, competing with LN, training AI on Materials, and using **Agentic AI** to log in, navigate, or query the Online Services (including via API calls) without written permission. Incidental use in a “Compliant AI Tool” with zero data retention is carved out and is **not** systematic/bulk extraction. — [LexisNexis General Terms](https://www.lexisnexis.com/en-us/terms/general/default.page)
- Thomson Reuters Canadian Onvio full terms (used here because a US Westlaw consumer ToS URL was not retrieved in this pass): unless previously authorized, customer must not “use any technology to automatically download, mine, scrape or index our data” or “automatically connect (whether through APIs or otherwise) our data to other data, software, services or networks.” Password sharing prohibited. — [Thomson Reuters Canada Onvio full terms](https://www.thomsonreuters.ca/en/onvio/full-terms.html)
- Unique evidence these products add vs public HTML: **named expert challenge history** (including trial-level orders that never become published opinions), **jury verdict/settlement hits** showing which side retained the expert and award ranges, **deposition and trial transcripts** in the vendor libraries, court-filed CVs, and docket analytics (CourtLink / Westlaw dockets) that can show the expert as a **party** (malpractice, fee disputes) rather than only as a witness. — [Lexis On-Demand](https://www.lexisnexis.com/en-us/products/expert-research-on-demand.page); [Expert Evaluator FAQ](https://www.experts.com/content/d/cv/EXPERT%20EVALUATOR%20REPORT.pdf)

### Inferences
- Human-use path that actually improves EWI without an API: (a) if the firm already has Lexis+/Westlaw, confirm in writing that **Profiler / expert docs / verdicts** are in-plan; (b) if not, buy **Lexis On-Demand** per opposing expert (~$164+$95+$66×N at 2016 list, if still valid) rather than a full research seat; (c) do **not** scrape either platform from NestJS.
- NestJS wire-in requires a **negotiated Lexis or TR API contract** that expressly names expert/docket content and permits incorporation into a client-facing report product. Expect enterprise pricing and a prohibition on using the feed to train models. Until that contract exists, adapters should stay catalog-only (matches the 22 Oct 2026 provider register).
- Small-firm vs enterprise: Westlaw Advantage public floor **$256.75–$399.75/mo** (≤10 attorneys, new). Lexis+ small-law floors are widely reported around **$114–$432/mo** but were not confirmed on a Lexis checkout page in this pass. Expert-specific content is often **add-on or out-of-plan**. Enterprise is quote-only at both vendors.
- Feeding Lexis/Westlaw materials into EWI’s LLM pipeline is a separate ToS problem even with a human download: Lexis §1.1(e)/1.2(h) tightly limits AI submission (ZDR, no training, not systematic). A NestJS job that bulk-loads transcripts into Gemini would likely be “systematic.”

### Gaps
- Current 2026 Lexis On-Demand dollar amounts: only the October 2016 PDF was found. Live page is quote-silent.
- Official Lexis+ 1–3 attorney price card was not retrieved (Spellbook is a reseller/content site).
- Whether Westlaw Advantage at $256.75 includes Profiler, Jury Verdicts, or expert transcripts is **not stated** on the Advantage FAQ; must be confirmed on an order form.
- US-specific Westlaw/Thomson Reuters Online Services ToS URL was not fetched; scraping ban is inferred from UK API terms + Canadian Onvio terms + secondary sources.
- No public price for Lexis CourtLink or Westlaw docket API calls.
- Bloomberg Law (VerdictSearch + ALM Experts) was not priced from an official page in this pass.

## Justia, Google Scholar case law, UniCourt, DocketBird, RECAP: coverage vs cost

### Takeaway
Free case-law HTML (Justia, Google Scholar) and the RECAP Archive overlap CourtListener opinions; they do **not** supply depositions, complete dockets, or named unpublished Daubert hits. UniCourt and DocketBird are the commercial PACER/state-docket layers with **published web prices and real APIs**. DocketBird is cheaper and federal-only; UniCourt adds state courts (relevant to Florida circuit PI) but API access is enterprise/quote. Neither replaces TrialSmith/Lexis transcripts.

### Cited Findings

**Justia**
- Public case HTML (SCOTUS, federal appellate from ~1950, some district from 2004, some state). No official REST/GraphQL API; third-party scorecard (verified Oct 2026) grades API existence as fail; only RSS/Atom for opinion summaries. Programmatic use “requires a bespoke commercial agreement.” — [Justia case law](https://law.justia.com/); [SuperGood Justia API report card](https://supergood.ai/api-report-card/justia)
- Justia TOS: user may not “Interfere with or disrupt the Service” or “Take any action that imposes an unreasonably or disproportionately large load on our infrastructure.” Justia may restrict, suspend, or terminate access. Not a clean “no robots” clause, but load and disruption are forbidden. Accessed 27 Oct 2026. — [Justia Terms of Service](https://www.justia.com/terms-of-service/)
- Third-party Apify “Justia Case Law Scraper” exists ($0.03199/result) and states Justia has no official API; **do not use this pattern for EWI** (scraping, and project rules forbid login/bot-wall bypass). — [Apify Justia scraper](https://apify.com/parseforge/justia-case-law-scraper/api/cli)

## Minimum court stack that fills empty “depositions / Daubert / lawsuits” sections public HTML cannot fill

### Takeaway
Public HTML (Justia, Scholar, clerk sites, CourtListener opinions) can fill **published** case names. It cannot fill **deposition transcripts**, **unpublished / trial-level Daubert-Frye-Rule 702 challenges**, or a reliable **party index of lawsuits against the expert**. The minimum stack that actually closes those three holes is: **(1) CourtListener REST + recap-fetch/PACER for federal filings and party search**, **(2) a human deposition bank (TrialSmith for plaintiff PI; Lexis On-Demand or Westlaw Profiler documents otherwise)**, **(3) Daubert Tracker for named gatekeeping hits**, and **(4) UniCourt or county clerks for Florida state-court lawsuits**. Items 2–3 are human/licensed, not NestJS, unless a vendor contract says otherwise.

### Cited Findings
- Daubert Tracker (MDEX Online) live fee schedule, accessed 27 Oct 2026: individual annual **$495**; 2-hour session **$50**; 30-minute **$25**. Group annual: 2 members **$450**; 3–5 **$675**; 6–10 **$1,000**; 11–50 **$1,250 + $25/user**; larger bands up to $4,000+. Documents in system **$7.50** with subscription / **$15** without; court-retrieved documents billed time-and-expense. Association discounts exist. Subscription includes unlimited search, non-fee documents, The Challenger weekly update. — [Daubert Tracker Ordering](https://dauberttracker.com/product/ordering.cfm)
- Conflict: CaseSearch pages archive a **November 2024** schedule at **$295/year** individual, $25/2-hr, $10/30-min. The live ordering page on 27 Oct 2026 shows **$495 / $50 / $25**. Use the live page. — [CaseSearch Daubert Tracker pricing](https://casesearch.ai/blog/daubert-tracker-pricing); contradicted by [live ordering.cfm](https://dauberttracker.com/product/ordering.cfm)
- Daubert Tracker homepage claims **257,133** case records and **196,876** expert records, federal and state gatekeeping standards, reported and “numerous unreported” cases, BriefBank of 10,000+ briefs from 1993, updated daily. Personal Injury is listed among top case types (4,525). BriefBank search is free; documents $7.50/$15. “Currently one out of every five cases in our complete database contains a supporting document.” No API found on public pages. — [Daubert Tracker](https://dauberttracker.com/); [BriefBank](https://dauberttracker.com/product/briefbank.cfm)
- Why public opinions fail this section: Daubert Tracker exists specifically because many gatekeeping rulings never name the expert in a published reporter, and trial-level orders live on dockets. — [Daubert Tracker](https://dauberttracker.com/); [CaseSearch explainer](https://casesearch.ai/expert-witness-search)
- PACER name searches and non-case-specific reports have **no $3 cap**, so “find every federal case where this expert is a party” is a real bill, unlike fetching a 40-page order (capped at $3). Transcripts of federal proceedings are also uncapped and appear ~90 days after production. — [PACER Pricing FAQs](https://pacer.uscourts.gov/help/faqs/pricing); [PACER Pricing: How fees work](https://pacer.uscourts.gov/pacer-pricing-how-fees-work)
- TrialSmith is plaintiff-only and forbids building a competing database; Lexis On-Demand sells transcripts at $66 (2016 sheet) without a research seat; Westlaw Profiler lists expert depositions/reports as documents (gov schedule $95). None of these three expose a public transcript API. — [TrialSmith Terms](https://www.trialsmith.com/?pg=TermsAndConditions); [Lexis On-Demand PDF](https://www.lexisnexis.com/pdf/Expert-Research-On-Demand_Services-and-Pricing.pdf); [CaseSearch Westlaw recap](https://casesearch.ai/expert-witness-search)
- PACER/RECAP/DocketBird do not cover Florida **state circuit** trial courts. UniCourt’s pitch is federal **and** state in one search; its web plans start at $59/mo. Florida clerk sites remain human/CAPTCHA. — [UniCourt Pricing](https://unicourt.com/pricing); [DocketBird MCP: federal only](https://www.docketbird.com/mcp/docs)

### Inferences

**Minimum stack (fills the three empty EWI sections)**

| Hole in public-HTML EWI | Minimum fill | Human vs NestJS | 2026 USD to budget |
|---|---|---|---|

**What not to buy for this gap:** extra Justia/Scholar seats (none exist), Google Scholar scraper APIs, UniCourt Personal if the only need is published opinions, DocketBird if the hole is Florida *state* lawsuits or depositions.

**Automation honesty**
- **Can wire into NestJS now:** CourtListener REST (working); DocketBird Falcon API (if subscribed); UniCourt Legal Data APIs (if enterprise contract); recap-fetch (proposed; needs PACER credential store + 180-day rotation + sealed-doc guard).
- **Can buy for a human, cannot wire:** TrialSmith, Daubert Tracker, Lexis+, Westlaw Advantage/Profiler, Lexis On-Demand, Justia, Google Scholar, RECAP browser extension, Florida clerk portals.
- **Do not scrape:** Lexis, Westlaw, TrialSmith, Google Scholar, Justia at crawler volume, PACER fee-free endpoints.

**Cheapest credible “close the three holes” annual budget for a small Florida plaintiff PI firm (order of magnitude, not a quote)**
- CourtListener: $0, or $250–$1,000/yr FLP membership if they want higher REST limits and are ≤5 attorneys / non-commercial-product use.
- PACER: $0 most quarters if under $30; budget **$50–$200/yr** if recap-fetch is used on every investigation.
- Daubert Tracker: **$495/yr** one user (live list).
- TrialSmith: **quote**; public anchor **$749/yr** Pro value + sporadic $28–$50 downloads, reduced by contribution credits.
- Skip UniCourt until a state-court lawsuit against the expert is actually a report requirement; then **$59/mo** Personal for a human, or enterprise API if NestJS must search state parties.

That combination is the minimum that public HTML cannot substitute. Adding Lexis+/Westlaw is justified when the firm already pays for research or needs verdict analytics and a done-for-you expert report; it is not the cheapest way to fill the three holes.
